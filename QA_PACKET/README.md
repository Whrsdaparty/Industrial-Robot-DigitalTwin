# QA Packet

This folder contains review notebooks for project governance, engineering controls, lifecycle documentation, digital-twin requirements, and safety concerns.

Each notebook is written for checklist-based review. Open the notebooks in Jupyter, VS Code, GitHub, or Codex and mark each checkbox as the document package is reviewed.

## Review Order

1. `01_project_direction_qa.ipynb`
2. `02_engineering_governance_qa.ipynb`
3. `03_lifecycle_commissioning_acceptance_qa.ipynb`
4. `04_digital_twin_qa.ipynb`
5. `05_safety_qa.ipynb`
6. `06_unresolved_questions.ipynb`
7. `07_recommended_changes.ipynb`

## Rule

Do not start major implementation until Tier 1 QA has been reviewed.
