# Industrial-Robot-DigitalTwin

Digital twin workspace for an industrial robot arm.

## Workspace Layout

- `DT/` - robot arm source folder. Leave this folder in place and do not reorganize it.
- `docs/references/` - research notes, PDFs, and supporting documentation.
- `vendor/freecad.robotcad/` - local RobotCAD FreeCAD workbench copy for robot-description tooling.

## Current Status

The workspace is being organized around the robot arm assets in `DT/`. The next milestone is to identify the robot model files in that folder and prepare a ROS2/Gazebo/RViz description workflow around them.
