# Exit Strategy to Codex

Purpose: ensure project continuity.

## Trigger Conditions
- Repository complexity increases
- Large code generation required
- Need iterative commits/tests

## Required Handoff Artifacts
- README
- CHANGELOG
- VERSION
- architecture
- roadmap
- requirements
- testing strategy
- risk register

## Codex Rules
Always:
- update changelog
- document code
- preserve safety notes
- preserve traceability
